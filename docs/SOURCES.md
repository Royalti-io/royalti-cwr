# Documents the rules cite

Every rule, field and lookup table is tied to the document it rests on by a slug. `sourceInfo(slug)` in `@royalti/cwr/reference` returns the title, the address and the edition.
CISAC addresses are member-portal links: they open only for a logged-in CISAC member. Nothing from these documents is copied into this package.
